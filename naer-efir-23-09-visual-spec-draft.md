Экран, судя по кадрам, менялся по ходу эфира: на sample_0010/0013 основная область светлая, на слайде «Миша, где продукт ещё слаб» (sample_0021/sheet_3) тот же экран уже показан в тёмной теме. Порядок появления версий по речи не проверен — нет расшифровки.

## 1. Библиотека — главный экран

Источник: sample_0010, sample_0013 (светлая версия), sample_0021 (тёмная версия внутри слайда).

**Каркас:**
- Слева фиксированный тёмный сайдбар (тёмно-серый/почти чёрный), справа основная область.
- Верх сайдбара: иконка-книга + «Reference Library» (белый текст, полужирный).
- Навигация верхнего уровня (иконка + подпись + счётчик справа):
  - «Библиотека» — активный пункт (выделен светлее фона), счётчик «100»
  - «К сборке»
  - «К просмотру»
- Заголовок раздела «Подборки» + иконка «+» справа (добавить подборку). Список — пользовательские папки, у Миши: «Финансы и покупки», «Здоровье и привычки», «Чаты и AI», «Медиа и развлечения», «Рабочие сервисы», «Контролы и компоненты», «Анимация и переходы», «Визуальные концепции» (два последних пункта обрезаны в кадре многоточием — точные полные названия не видны, нужна сверка).
  - У Дани (`danyaeast.com`) набор подборок другой и длиннее: «Визуальные приёмы», «Движение», «Навигация», «Мобильные паттерны», «Готовые компоненты», «Библиотеки», «На потом», плюс тот же общий блок тем — значит список подборок это пользовательские данные, не фиксированная навигация.
  - Низ сайдбара: «Корзина» со счётчиком (100/109 у разных инстансов), «Настройки». У Миши ещё подпись мельче — «На этом компьютере».

**Основная область:**
- Хедер: иконка-гамбургер + заголовок «Библиотека» (H1, чёрный на светлой версии). Справа кнопка «+ Добавить» — заливка синяя/сине-фиолетовая (оценка по пикселям, ближе к `#4f6bff`–`#5b7cfa`), текст белый, форма — pill (полностью скруглённые углы).
- Поисковая строка на всю ширину: скруглённый прямоугольник, иконка лупы, плейсхолдер «Найти референс».
- Ряд фильтров: три кнопки-пилюли с шевроном вниз — «Стадия ⌄», «Фильтры ⌄», «Вид и порядок ⌄» — белая заливка, тонкая обводка, чёрный текст.
- Строка счётчика: «100 референсов» (серый, мелкий) слева, «Выбрать» (синяя ссылка) справа.
- Сетка карточек, в кадре видно 3 колонки на широком экране (реальное число колонок при разных viewport не проверено).

**Карточка референса:**
- Превью (картинка или видео), поверх — плашка в левом верхнем углу: иконка + подпись «Изображение» либо «Видео» (тёмная полупрозрачная подложка, белый текст, скруглённая).
- Встречается вторая плашка в правом верхнем/нижнем углу превью — короткий лейбл из самого референса («Move to cash») либо числовой бейдж («48» на круговой диаграмме) — это, похоже, элемент самого референса, а не системный бейдж; нужна сверка на видео.
- Подпись под превью — техническое имя файла, мелким моно-подобным шрифтом, напр. `ggox1gkxmaamwlj?format=jpg-name=900x900`, `1736661617226490160?s=20.mp4`, `Screenshot 2026-09-14 at 16.11.52`.
- Под подписью — ряд из трёх маленьких точек-индикаторов (назначение по кадру не считывается — возможно карусель нескольких изображений референса либо индикатор состояния разбора; нужна сверка).

## 2. «Путь продукта» — вьюер артефактов

Источник: sample_0019, подтверждено на sheet_3.

- Верхняя панель (тёмный фон): слева лого «Рефы» + мелкая подпись «Материалы эфира»; справа ссылка «Открыть отдельно ↗».
- Ряд вкладок: «Путь продукта» (активна) / «Артефакты».
- Под вкладками: хлебная крошка «← Назад к карте» | «Просмотр референса» (текущий, жирным); справа кнопка «Скачать исходник».
- Тело документа на тёмном фоне: заголовок «Поведение панелей» (белый, ~20px), текст абзацами (светло-серый, что-то около 14px, межстрочный интервал свободный, колонка читаемой ширины — точное значение в px не измерено).

### Параметры из документа «Поведение панелей» (расшифровано построчно с кадра, не проверено по видео повторно)

| Параметр | Значение |
|---|---|
| Ширина оболочки (desktop) | вся ширина viewport, без ограничения 1920px |
| Боковой отступ | 24–56px |
| Промежуток между областями | 20–48px |
| Ширина панели в покое | 256–336px, плавно зависит от viewport |
| Ширина панели при взаимодействии | на 64px больше состояния покоя |
| Ширина панели на 1024–1279px | 224px / 280px |
| Сдвиг центра grid | 32px (28px на небольшом desktop) — вдвое меньше первоначальной версии |
| Непрозрачность панели по умолчанию | 50% |
| Непрозрачность на hover/focus | 100% |
| Переход ширины | 240ms |
| Переход прозрачности | через Motion, без конкурирующего CSS transition |
| Заголовки панелей | «Разбор и сборка», «Информация» — без иконок, стрелок, некликабельны |
| Переключатели панелей | только в нижней мобильной навигации |
| Вкладки центрального холста | общий `TabPanels`, crossfade 140ms; уходящая панель помечается inert и удаляется после перехода, не перехватывает клики |
| Высота области / позиция переключателя | не меняются при переключении вкладок |
| Быстрые переключения | перенаправляют CSS transition; клавиатурная навигация и reduced motion — без задержки |
| Возврат на вкладку исходника | не запускает повторную анимацию увеличения из карточки — она только при первом открытии |
| Брейкпоинт явного открытия панелей | до 1024px — кнопки «Работа» и «Информация»; открытая панель занимает область холста, тело скроллится, закрытие возвращает прежний режим |
| Touch | подписи карточек не зависят от hover |
| Reduced motion | анимация увеличения отключена, пространственные CSS-переходы отсутствуют, видео не автозапускается |
| Метка «просмотрено» | не ставится от одного открытия исходника/информации; ставится при взаимодействии с панелью работы или прямом переходе к разбору из очереди |
| Бэкенд | MCP/API, сохранение авторского смысла, выбор версий, корзина и фильтры — на прежнем domain/backend |
| Иконки приложения | восстановлены из `main` вместе с исходными Stroke SVG и генератором, без новой сетевой зависимости |

Это, судя по всему, лишь один документ из набора «Артефакты» — на карте (sheet_3, второй кадр верхнего ряда) видно ещё несколько цветных блоков-узлов с превью, названия не читаются в этом разрешении. Нужны кадры покрупнее или видео, чтобы разобрать остальные артефакты.
